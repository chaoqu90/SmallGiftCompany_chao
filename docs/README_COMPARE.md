# UX Comparison Guide

These three specs intentionally keep the same Phase 02 product functionality and compare only UX/visual direction.

## Branches
Implement each on a separate branch:

```text
ux/playful-boutique
ux/scandinavian
ux/party-pop
```

Keep identical across all branches:
- backend APIs
- mock/seed data
- product images
- routes
- business logic
- bundle/filter results

Change only:
- MUI theme/tokens
- layout/styling
- typography
- visual interactions
- microcopy explicitly specified in the chosen UX document

## Options

### A — Playful Boutique
Best overall balance of:
- parent trust
- kid appeal
- small-brand warmth
- e-commerce usability

### B — Scandinavian / Modern Kids
Best for:
- premium positioning
- parent confidence
- photography-led brand
- thoughtful/curated perception

### D — Party Pop
Best for:
- booth impact
- celebration energy
- memorable branding
- packaging/social/QR-card consistency

## Screens to Compare
Compare the exact same states:

1. Mobile homepage
2. Gift Finder with active selections
3. Mobile Bundle Gallery
4. Desktop Bundle Gallery
5. Bundle Detail
6. Loading state
7. Empty-results state

## Parent Evaluation
Ask:
- Does this feel trustworthy?
- Is price immediately clear?
- Can I tell what is inside?
- Does it feel easy rather than overwhelming?
- Would I feel comfortable eventually checking out here?

## Kid Evaluation
Ask:
- Which site looks most fun?
- Which bundle would you tap first?
- Can you identify themes quickly?

## Booth / Brand Evaluation
Ask:
- Which looks best on a QR sign?
- Which is easiest to remember?
- Which can extend to packaging and social media?

## Important
Do not choose from desktop screenshots alone.

The main acquisition journey is:
```text
booth QR → parent phone
```

Mobile should carry more weight than desktop in the final decision.
